# JSP-000301 — Lean 4 formalization of the disproof of Erdős problem #365

**Problem (Erdős #365):** If two consecutive positive integers are powerful, must at least one be
a perfect square? **Answer: NO.**

This repository contains a complete Lean 4 + Mathlib formalization of the disproof. The main
theorem `JSP000301.erdos_365_witness` proves the existence of a pair of consecutive powerful
numbers neither of which is a perfect square:

```lean
theorem erdos_365_witness :
    ∃ m : ℕ, IsPowerful m ∧ IsPowerful (m + 1) ∧ ¬IsSquare m ∧ ¬IsSquare (m + 1)
```

It is derived from `counterexample_family (n : ℕ)`, a pure-Lean construction of an **infinite
family** of such pairs mₙ = 23³·Xₙ² and mₙ+1 = 2³·Yₙ², generated by the Pell unit
ε = 1184384449 + 3796260·√97336 satisfying 8·Yₙ² − 12167·Xₙ² = 1. The base case n = 0 gives
m₀ = 12167 = 23³ — the classical counterexample. All arithmetic is recomputed by the Lean kernel
(`norm_num`, `ring`, `linarith`, `omega`, `positivity`, `linear_combination`) at compile time —
no external assertions, no `#eval`, no `sorry` / `admit`.

## Axiom dependencies (disclosed)

Both target theorems depend only on the **three standard classical Lean axioms**:

```
propext, Classical.choice, Quot.sound
```

These are the ordinary axioms used throughout Mathlib (propositional extensionality, the axiom of
choice, quotient soundness). Their use is standard, permitted, and **not** disqualifying. There is
no `sorry`, no `admit`, and no added unproved assumption. See [`axioms_audit.md`](axioms_audit.md)
for the verbatim `#print axioms` output and the reproducible audit procedure.
